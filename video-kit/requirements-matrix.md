# Requirements matrix

> **Prototype by Rashed Atieh for evaluation — not an official Almamlaka TV product.**

The nine requirements of the client brief, in the brief's own words and order, each traced to how it is
met, where the code is, which tests cover it, the live result, and what the video shows.

Test names are real functions in `tests/`. Acceptance IDs refer to `docs/ACCEPTANCE_TESTS.md`.

## End-to-end results per requirement

From the full live run on the 48 gold questions (`eval/reports/e2e/record.md`; metrics defined in `eval/run_e2e.py`):

| Requirement | Measure | Result |
|---|---|---|
| R1, R2 | Answers when the documents can, abstains when they can't | 48/48 (100%) |
| R3 | At least one cited chunk is a gold chunk | 39/40 (98%); English 25/26, Arabic varieties 14/14. The one miss is A-04 (`What is the total development budget across all quarters?`): answered `partial`, citing the Budget Notes (BUD-p1-s2) instead of the quarterly table (BUD-p1-s1) |
| R4 | Known disagreements flagged | 5/5 (100%); English 2/2, Arabic 3/3 |
| R6 | Reply in the question's language | 47/47 (100%); English 33/33, Arabic varieties 14/14 |
| Cost and speed | Per turn | $0.0137 ($0.6580 for the 48 questions); latency median 8.2 s, p90 15.84 s, max 33.89 s |
