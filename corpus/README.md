# Knowledge base (not included)

The three source PDFs belong to Almamlaka TV and are not redistributed in this public repository:
`Almamlaka_Project_Overview.pdf`, `Almamlaka_Budget_Timeline.pdf` and `Almamlaka_Team_Governance.pdf`.
Their checksums are in `corpus_manifest.json`. Put the files here and run `make index` to rebuild the index
from the originals. The committed index in `data/index/` already lets the app and its tests run without them.
